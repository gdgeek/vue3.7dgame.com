# 场景名称与日期格式

场景名称以清楚表达用途为主，不需要日期时保留普通名称。需要用日期区分版本时，先调用全局只读工具 `xrugc_format_scene_name`，统一使用 `名称_YYYY-MM-DD_HH-mm-ss`，不要自行采用 `20260921`、单独日期或括号日期等不同后缀。规范后缀会在场景标题中显示为右上角的日期时间角标，完整名称仍用于保存和查询。

## 生成规范名称

先用 `xrugc_get_authoring_capabilities` 和 `xrugc_get_authoring_tool_schema` 确认当前页面实际工具及 schema。格式化工具接收：

- `baseName`：不带日期后缀的基础名称，保留有业务意义的文字和下划线。
- `timestamp`：可省略，省略时使用调用时的当前真实时间；显式提供时必须是带 `Z` 或偏移量的 RFC3339 时间，不接受只有日期或没有时区的时间。
- `timeZone`：可省略，省略时使用浏览器本地时区；显式提供 IANA 时区，例如 `Asia/Shanghai`。日期和时间从同一个时区生成，不混用 UTC 日期和本地时间。
- `refreshTimestamp`：克隆场景或组件时设为 `true`。工具会使用本次时间替换已有时间，不再追加第二段时间；省略时保留已有规范名称。

例如，调用：

```json
{
  "baseName": "科学护眼 · 独立课程验收",
  "timestamp": "2026-09-21T11:00:05+08:00",
  "timeZone": "Asia/Shanghai"
}
```

返回的 `name` 为 `科学护眼 · 独立课程验收_2026-09-21_11-00-05`。将它原样传入 `xrugc_stage_authoring_creation` 的 `name`，并设置 `kind:"scene"`；不要再追加日期或改回其他日期写法。后续仍通过 `xrugc_complete_authoring_draft` 请求页面确认、`xrugc_get_authoring_operation` 核验创建回执。

结果还提供 `baseName`、`date`、`time`、`timeZone`、`timestampSource`、`format` 和 `nextStep`。`timestampSource` 为 `current` 表示当前时间，`provided` 表示显式时间，`existing` 表示沿用已有规范后缀。可据此核对名称来源，不将标题时间当作数据库创建时间。

## 已有名称与历史日期

`baseName` 已带完整规范后缀、未指定 `timestamp` 且没有设置 `refreshTimestamp:true` 时，返回原规范名称，不重复追加时间。名称后缀没有记录时区，工具此时返回 `timeZone:null`，不能据此推断原时区或转换原时间；需要换成指定时间时，显式提供 `timestamp` 和适用的 `timeZone`，工具会替换已有规范后缀。

## 克隆场景与组件

克隆时将原名称作为 `baseName`，并传 `refreshTimestamp:true`。例如：

```json
{
  "baseName": "科学护眼_2026-09-21_11-00-05",
  "refreshTimestamp": true,
  "timeZone": "Asia/Shanghai"
}
```

工具取调用时的真实当前时间，返回 `科学护眼_本次日期_本次时间`。第二次、第三次克隆继续替换末尾时间，正文不变；可以显式传 `timestamp` 选择本次时间。旧的重复规范时间、明确的 `（副本 YYYY-MM-DD HH:mm:ss）` 及页面历史生成的多语言副本标记会先被清理，结果只保留一个新后缀。不要自行把新时间拼接在完整原名之后。

页面的组件复制确认框也使用这条规则，用户可以在确认前修改名称。场景包导入/复制在服务器端对场景和组件更新后缀，同一包内共用一次导入时间；素材名称不新增时间。格式化工具只准备克隆名称，不复制对象内容；仍通过实际的克隆入口完成操作并核验结果。

历史名称中的 `20260921`、`2026-09-21` 或 `（2026-09-21）` 可能指活动日期、内容版本或业务编号。工具不会猜测或自动删除这些内容；调用前应先确定不含日期后缀的基础名称和时间含义。仅知道历史日期时不要编造时分秒，可以保留业务名称，或按任务要求生成一个当前时间版本。

格式化只生成文本，不创建草稿、不修改或重命名已有场景，也不代表已保存。整理已有名称需通过实际可用的重命名入口另行执行并核验；用户未要求整理时，不批量改写历史标题。
